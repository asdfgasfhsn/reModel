# reModel status

The tracking table: what is done, what is in progress, and the game-by-game
history. The README has the short version; the findings are in [docs/games/](games/README.md) and [docs/hw/](hw/).

## Status

Thirty-four games run, from boot through attract and coin-up into play, in a
native window (`make play`) and in the browser (`make web`), with live sound,
controls and save states. The table below tracks each part; the first rows
date from bringing up `topskatr`, the first game.

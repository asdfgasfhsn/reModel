# Top Skater's named game values: NAME|ADDR:WIDTH[:signed|:float]|what it is, how it was found
# (docs/uplift-studio.md, "Named values"). Work-RAM words found by running
# the game with `remodel ram search` / `ram show` on reproducible tours and
# read against rendered frames. WIDTH is b, w or l (little-endian); floats
# are IEEE singles. Frames are counted from power-on. Addresses are for the
# game's one program ROM set. Anything unconfirmed says so.
screen|0x5dc090:l|The game's mode word. Seen: 32 boot text (frame 300), 40 SEGA logo (450) and also the press-start screen (1150, so 40 does not name one screen), 20 title (800), 12 course select (1350-2000), 11 skater select (2050-2850), 0 between select and the GO (2900-3100, not looked at), 7 racing including the GO and TIME UP (3150-8200), 38 Game Over (8250-8350). Found by search on coin-start for a word that differs between those phases and holds within each (small values only), then read every 50 frames and matched to rendered frames at 300, 450, 800, 1150, 1500, 2100, 3300, 8100, 8300. From the Novice run of 19,368 frames: 20 the Result screen (frame 12500: S class, ranking arrow), 170 the staff roll over the replay (13000-15500), 64 its last stretch (16000), 0 (16500), 32 (17000-17500), 12 course select again (18000), 40 attract (18500 on). Other codes exist and are unmapped.
course|0x57bfa4:l|Course raced: 0 Novice, 1 Expert. Valid once the race has loaded (flips at about frame 2900); 0 before then, so 0 does not mean Novice until screen is 7. Found by diffing small RAM words between a coin-start tour (Novice, limit 58 at the GO) and the same with selright at 1330 (Expert, night stadium, limit 48); the only word that differed after the load and stayed. A second flag, 0x5830a4, is 1 from the end of course select for Novice and stays 0 for Expert. An Expert race that loads with jump front held also reads 0 here (the secret-event check is then installed; it sets this to 1 if it gives up).
skater|0x5dcdfc:l|Skater chosen (and the cursor while choosing): 0 Ash, 1 Keith, 2 Ken-ta, 3 J, 4 Cookie, 5 Jill. Found by diffing tours that press selright 0 to 3 times on skater select (words 0,1,2,3); names read off the skater select screen for each cursor position (frame 2500); the names of 4 and 5 are read off the same screen, and the value was read at frame 2500 for 4 and 5 too. 0x5dce24 holds the same number.
clock|0x5830b0:w|LIMIT countdown, in frames (60 a second); the HUD shows whole seconds (floor of value/60). Not running before the GO. Found by search (fell 300 over 300 frames); read against the HUD at frames 3300 (3503, limit 58), 3900 (2903, 48), 4000 (2803, 46), 4400 (2583, 43), 4500 (2483, 41) of a Novice run. It can be extended during a run (see the poke table's hold-clock).
total-time|0x5830d0:l|TOTAL TIME in frames since the GO (60 a second); the HUD shows it as minutes, seconds and hundredths, one frame behind this value. Read at frames 3600 (456, HUD 0'07"58), 3900 (756, 12"58), 4000 (856, 14"25), 4400 (1256, 20"91), 4500 (1356, 22"58). Found by comparing the counter that rose by 1 a frame with the HUD.
score|0x582fc0:l|SCORE as the HUD shows it. Found by search (rose with jumps in a tour that presses jumpfront every 60 frames: 0, 2021, 3842, 6286); read against the HUD at frames 3900 and 4000 (2021), 4400 (3842) and 4500 (6286).
speed|0x582f90:l:float|The skater's speed in world units per frame (about 1 to 4.4 on the Novice and Expert runs, 0 when stopped). Found by correlating every word of 0x580000-0x58ffff with the distance the position moved per frame (correlation 0.996 over 81 frames; 3.26 against 3.26 measured at frame 3300). The gauge shows no number; 0x5828a0 (a long) is about 21.3 times it, probably the gauge's value, unconfirmed.
pos-x|0x583034:l:float|Skater world position x (sideways). Found beside the orientation matrix at 0x583010; moves with curving input (0 to -70 over 3300-3400 holding curving=0x50, back to +64 with curving=0xb0) and its frame-to-frame distance with y and z equals speed. Not read against the screen directly.
pos-y|0x583038:l:float|Skater world position y (up). A jump raises it (about 17 units over a hop at frames 3304-3352 of a jumpfront tour, matching the skater in the air at 3328 and on the ground at 3360); the Novice course slopes down so it falls over a run.
pos-z|0x58303c:l:float|Skater world position z (forward, falls as the skater goes down the course, about -4000 at frame 3300 of the tour that presses jump).
heading-x|0x583028:l:float|With heading-z, the skater's heading: yaw = atan2(heading-x, heading-z) in radians, 0 along -z, positive towards +x (two elements of the 3x3 orientation matrix at 0x583010-0x583030). Found by testing every pair of those nine floats against the direction of motion of the position; the best pair's median error was 1.2 degrees over 80 frames from 3300 to 3700 of the Expert tour. Unconfirmed against the screen; the camera may share the matrix. Note heading-z is positive (about 1) while the skater runs down the Expert course towards -z, so read the direction of travel from vel-x and vel-z, which the secret-event check uses, not from these two.
heading-z|0x583020:l:float|The other element of the heading; see heading-x.
airborne|0x509e65:b|1 while the skater is off the ground, else 0. Found by search for a byte that changed between ground and air frames (a long fall at 3918-4008 of the Expert tour, y rising then falling); also 1 in short hops. Read against the picture: 1 at frame 3328 (arms out, shadow detached below) and 0 at 3360 (crouched, shadow under the board) of a jumpfront tour. At take-off it can lead or lag the picture by a few frames.
character|0x582f00:l|The character id the game uses (not the skater cursor): the cursor 0-5 (skater) is mapped through a six-entry table in the program ROM to 1, 2, 4, 0, 5, 3 (Ash 1, Keith 2, Ken-ta 4, J 0, Cookie 5, Jill 3, by the names on skater select), set when the cursor moves. 6 is Alex and 7 is P-Nut, the two hidden skaters (see the tours `hidden-alex` and `hidden-pnut`); read as 6 after the Alex code and 7 after the P-Nut code at frames 1300 and 1450. The ROM's table holds 8 entries.
code-pos-0|0x5dce18:l:signed|Progress of the first secret-code matcher (the skater-select code for Alex, and the course-select code for the big-skater mode): 0 to 5 steps matched, 6 complete, -1 failed (it stays failed until the screen is left). Found from the matcher in the program ROM and read at frames 1139-1300 of the `hidden-alex` tour (2 after the two idle steps, 4 after the left taps, 5 after the right, then 6 and the id changes to 6).
code-pos-1|0x5dce1c:l:signed|The second matcher's progress (skater select, for P-Nut): 0 to 5 matched, -1 failed. At 5 it waits for the start button's release (the id then becomes 7). Read at frames 1130-1300 of the `hidden-pnut` tour (0, 1, 2, ... 5).
secret-flag|0x5ce960:l|1 after the course-select code of the big-skater mode (see docs/games/topskatr.md), else 0: it switches the pair of routines at 0x5ce970 and 0x5ce974 and the skater is drawn very large on skater select and in the race. Read as 1 from frame 965 of the tour `big-skater`.
course-cursor|0x5830c8:l|The course-select highlight: 5 Novice, 0 Expert (the game's own coding; `course` is set from it later), 8 for the secret event, set 90 frames after its banner (confirmed: the skate park of the tour `secret-event`; docs/games/topskatr.md, "Hidden content"). Read at frames 770-1100 of the `big-skater` tour (5 on Novice, 0 on Expert in the tour `expert`).
course-kind|0x5830a4:l|1 for Novice, 0 for Expert, 2 for a third choice that the code handles (a different routine at ROM 0x3e450 is installed for 2) but that no input found reaches: course-cursor can only read 5 or 0 on course select. Unconfirmed that 2 is playable.
section|0x5830ac:l|The course section counter: 0 at the GO, rising by one about every 60 frames of the Expert route (3 at race frame 195, 12 at 920, 17 at 1140) as the skater passes along the course; the game rewrites it every frame, so a poke of it never reaches a reader. The secret-event check gives up when it passes 19 (the event can only be reached in the first part of the Expert course). Found by reading the check at ROM 0x392d0 and watching the value along the Expert recording; the meaning (a section index, not seconds) is inferred from it rising with distance.
lead-x|0x582f10:l:float|The x of the point the secret-event check measures from: the skater object's first vector (object at 0x582f10, pointed to by 0x5826b4). It leads pos-x by about six frames of motion (pos-x + 6 * velocity), and in y sits about 12 units below pos-y. Found by reading the check (0x392d0) and comparing it with pos-x/y/z along a run (24.2, -2.8, -838.2 against 22.4, 9.2, -817.9 at frame 3401 of the armed Expert tour `expert-jump-held`). The game rewrites it every frame.
lead-y|0x582f14:l:float|The y of the lead point; see lead-x.
lead-z|0x582f18:l:float|The z of the lead point; see lead-x.
vel-x|0x582f60:l:float|The skater's velocity x (the skater object's +0x50); the secret-event check wants vel-x / speed above 0.5 (travelling towards +x). Found by reading the check and matching it with the position's change per frame.
vel-y|0x582f64:l:float|The skater's velocity y; see vel-x.
vel-z|0x582f68:l:float|The skater's velocity z (about -3 on the straight; the check also adds 0.006 times it).
skater-cc|0x582fdc:l:signed|A skater object word (+0xcc) that is -1 all through the Expert recording; the secret-event check ends itself (sets course to 1 and removes its task) when it is above 0, so the event is lost then. Not seen above 0 in play: its meaning is unconfirmed (a wipe-out state?). Poked to 1 for a frame it did end the check (a test, not a route).
mode-fn|0x582660:l|The address of the game's per-frame mode routine: 0x36590 while racing, 0x5de10 between races, and 0x5de10 once the secret-event check has fired (its code stores it before calling the event). Read as 0x36590 until frame 3996 and 0x5de10 from 3997 of the tour `secret-event`.
secret-banner|0x58253c:l|The frame counter of the secret event's banner "WELCOME TO SECRET EVENT!!": 0 when the check fires, up to 90 (0x5a), then 91 and the game restarts into the event (course-cursor becomes 8, screen 0). Read each 10 frames from 3997 of the tour `secret-event`.
